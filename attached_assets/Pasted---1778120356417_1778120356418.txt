يد تطوير وتحسين نظام  الحالي بدون تغيير البيانات الحالية أو التأثير على الشركات المسجلة. نفّذ جميع النقاط التالية باحترافية وبنية قابلة للتوسع والنقل مستقبلاً إلى سيرفر خاص.

1. قاعدة البيانات والبنية
 • استخدم PostgreSQL كقاعدة بيانات رئيسية.
 • النظام يجب أن يكون Multi-Tenant بحيث كل شركة معزولة بالكامل عن الأخرى باستخدام Company_ID.
 • دعم migrations لكل تحديث مستقبلي بدون فقدان البيانات.
 • فصل جميع الإعدادات الحساسة داخل ملف .env.
 • اجعل النظام portable وقابل للنقل لأي VPS أو Oracle Cloud مستقبلاً.

2. النسخ الاحتياطي والاسترجاع
 • إنشاء نسخ احتياطي تلقائي يومي لكل شركة بشكل منفصل.
 • النسخ تشمل:
 • الموظفين
 • الحضور والانصراف
 • الرواتب
 • الأقسام
 • الفروع
 • الصلاحيات
 • المحادثات
 • الإجازات
 • جميع التقارير
 • حفظ النسخ داخل storage آمن ومنظم حسب:
Company_ID + Date + Time



• إضافة لوحة داخل حساب Super Admin تحتوي:
 • عرض جميع النسخ الاحتياطية
 • تاريخ النسخة
 • حجم النسخة
 • الشركة التابعة لها
 • زر Restore
 • زر Download
 • زر Delete
 • عند الضغط على Restore:
 • استرجاع النسخة بدون تلف البيانات
 • إيقاف مؤقت للخدمة أثناء الاسترجاع
 • إشعار بنجاح العملية

⸻

3. نظام الموقع GPS

داخل حساب مدير الشركة:
اريد تلغي موقع الشركة و اضافة الموقع لكل فرع ويرتبط الموضف بالفرع ويسجل دخولة حسب موقع الفرع المنتمي له
و

إضافة إعداد:

Attendance Location Mode

خيارات:

Enabled
 • الموظف لا يستطيع تسجيل الدخول إلا داخل نطاق GPS المحدد.

Disabled
 • الموظف يستطيع تسجيل الدخول بدون طلب الموقع.
 • يجب أن يتم حفظ الإعداد لكل شركة بشكل مستقل.
